AI 编程工具越来越多，Claude Code、Cursor、Codex、Gemini 换着用，一个月下来账单上那个数字到底花在哪了，没几个人能说清。厂商只告诉你"总共花了多少"，不告诉你"花在了什么上"——是写代码、是反复重试，还是跟模型来回聊天烧掉的。

CodeBurn 就是来解决这件事的。它是一个完全本地运行的免费工具，`npx codeburn` 一行命令就能跑起来，把 Claude Code、Cursor、Codex、Gemini、Grok 等几十个 AI 编程工具的 token 消耗和成本全部统计进来，还能按模型、按项目、按任务一层层拆开看。

**项目地址：**https://github.com/getagentseal/codeburn

它跟一般"成本统计"工具最大的不同，在于不靠包装 API 调用来计数，而是直接读硬盘上本来就存在的会话记录。Claude Code 的 JSONL 对话日志、Cursor 的 state.vscdb 数据库……这些数据一直躺在本地，CodeBurn 只是把它们解析出来、归好类。所以它不需要 API key，不经过任何第三方，数据不出机器。

![CodeBurn 的交互式 TUI 仪表盘](https://raw.githubusercontent.com/getagentseal/codeburn/main/assets/dashboard.jpg)

比较有意思的是它的分类方式。每一笔消耗都被归进 13 个类别——写代码、调试、重构、写测试、探索代码库、规划、派生子 Agent、Git 操作、构建部署、纯聊天等等。这个分类是纯确定性的，不调用任何大模型，靠的是工具调用模式和关键词规则。换句话说，你看到的数字是实打实测出来的，不是模型"猜"的。

有人拿自己 30 天的真实数据做了个统计：7890 美元的 AI 编程开销里，只有 47.9% 真正花在了产出代码上，剩下的一大半，都耗在了探索代码库、调试、派发子任务和来回对话上。这个结论挺有冲击力——账单上的总数，跟"真正写出代码"之间的距离，比多数人以为的要大得多。

![CodeBurn 支持的 providers 清单](https://raw.githubusercontent.com/getagentseal/codeburn/main/assets/providers.png)

它还有一个"一次到位率"的指标：把编辑、测试、修复的循环识别出来，算出一项编辑有多少比例是第一次就做对的。一次到位率高，说明模型稳定；低，说明在重试循环里烧 token。配合 `compare` 命令，可以把两个模型放在一起比——同样的活，哪个一次到位率更高、单次编辑成本更低，用你自己的数据说话。

除了命令行，它还有 macOS 菜单栏、Windows 托盘、Linux GNOME 扩展和网页版仪表盘。`overview` 命令能生成一份可以复制粘贴的月度总结，发到群里、贴进 PR 都行。

![CodeBurn 网页版仪表盘](https://raw.githubusercontent.com/getagentseal/codeburn/main/assets/web.jpg)

这个项目四月发布，现在 GitHub 上已经 1.1 万多 Star，今天一天就涨了 779。涨得这么快，说明"钱花哪了"这个痛点比想象中普遍。随着 AI 编程工具从订阅制转向按量计费，这种看得见每一分钱去向的工具，会越来越像一个刚需。

它适合同时用着好几个 AI 编程工具、又不想在账单面前两眼一抹黑的人。偶尔让 AI 改两行代码的，用不上这么细的统计；但只要用量上来了，它就是帮你把账算清楚的那把尺子。

项目地址：https://github.com/getagentseal/codeburn
