深夜十一点，你把一份 50 页的 PDF 行业报告丢给 AI，说“帮我做成 PPT”。三分钟后，它吐出来一个文件。你打开一看——每一页都是一张截图。文字改不了，图表动不了，对齐全靠猜。

你又试了另一个工具。这次好一点，给了你可编辑的文本框。但每一页的布局都像是模板硬套的：标题在左上角，正文在正中间，图片被压成扁的。你想把第二页的图表挪到第三页，结果整个排版全乱了。

你不是在“做 PPT”，你是在“修 PPT”。

今天雷达君要安利的这个开源项目，就是来终结这种“AI 生成的 PPT 只能看不能改”的局面的。它输出的每一页都是**原生的 PPTX**——形状、文本框、图表、表格，全部是 PowerPoint 原生对象，你可以像手搓一样随意编辑。

它就是——**PPT Master**。

## 01 ｜核心逻辑：不是填模板，是真的在“做”PPT

PPT Master 的核心理念用一句话就能说清楚：**给你一个真正的 PPTX，不是一张截图，不是一个填好字的模板**。

市面上绝大多数 AI 生成 PPT 的工具，走的是两条路。第一条是“截图流”——把每一页渲染成图片塞进 PPT 里，你拿到的是一个“看着像 PPT 的 PDF”。第二条是“模板流”——先预设好一套布局，然后把你的内容硬塞进去。你改不了结构，只能改文字。

PPT Master 走的是第三条路：**它直接操作 PowerPoint 的原生对象模型**。

你丢给它一份 PDF、Word 文档、网页链接，或者干脆就是一个主题。它先用 AI 理解内容、梳理逻辑、构建叙事结构。然后，它调用 PowerPoint 底层的 DrawingML 引擎，在 PPTX 文件里**原生生成长出形状、文本框、图表、表格**——不是把图片贴上去，是一笔一画地“画”出来。

你打开生成的 PPTX，每一个元素都是可选的、可拖的、可改的。想调整标题位置？拖一下。想改图表数据？双击编辑。想把第三页的布局复制到第五页？直接复制粘贴。

**你拿到的不只是一份 PPT，而是一个可以继续生长的文件。**

> 这个项目由一位金融从业者（CPA · CPV · 咨询工程师）Hugo He 开发。他每天都要审查和编辑演示文稿，市面上那些“生成即终结”的 AI 工具根本满足不了他的需求。他要的是 AI 帮他完成 80%的粗活，剩下 20%的精细调整留给自己在 PowerPoint 里完成。

## 02 ｜硬核功能盘点

> 🔗 **GitHub 地址**：https://github.com/hugohe3/ppt-master

### 1. 原生 PPTX：不是截图，不是模板，是真正的 PowerPoint

这是 PPT Master 最核心、最拉开差距的能力。

你生成的每一页 PPT，包含的都是**原生的 PowerPoint 对象**——形状（Shape）、文本框（TextBox）、图表（Chart）、表格（Table）。你可以在 PowerPoint 里随意编辑、移动、缩放、改颜色、调字体。

它甚至支持**幻灯片母版（Slide Master）** 和**你自己的.pptx 模板**。你用公司统一的模板文件喂给它，它生成的 PPT 直接套用你公司的字体、配色和版式规范。

### 2. 数据驱动的图表和表格

PPT Master 不只是把文字塞进 PPT 里。它还能根据你的数据**原生生成长出图表和表格**。

你丢给它一份带数据的文档，它会自动识别数据、选择合适的图表类型、生成带有数据绑定的原生 Excel 图表。双击图表就能编辑数据源，和你在 PowerPoint 里手搓的图表一模一样。

### 3. 过渡动画 + 音频旁白

PPT Master 生成的 PPTX 支持**原生过渡动画（Transitions）和对象动画（Animations）**。每一页的切换效果、每一个元素的入场顺序，都是真正的 PowerPoint 动画，不是视频。

更硬核的是，它支持**从演讲者备注生成音频旁白（Audio Narration）** 。你写好每一页的备注，PPT Master 会用 TTS 生成对应的语音，嵌入到 PPTX 里。打开 PPT，每一页都会自动朗读。

### 4. 多种输入源：PDF、DOCX、网页、纯主题

PPT Master 支持几乎你能想到的所有输入格式：

- **PDF**：提取文字、图表、图片
- **DOCX**：读取 Word 文档结构
- **网页链接**：抓取并理解网页内容
- **纯主题**：只给一个主题，AI 自己构思内容

配合 Kimi K3 的百万 Token 上下文窗口，它甚至能一次性处理整本 PDF 或整篇论文。

### 5. 多风格模板：从杂志风到赛博朋克

PPT Master 内置了多种视觉风格，你可以在生成时指定：

- **Editorial Magazine**：建筑摄影 + 冷静排版
- **Data Journalism**：Bloomberg 风格深色仪表盘
- **Swiss Grid**：瑞士网格 + 红色点缀
- **Glassmorphism SaaS**：毛玻璃 + 渐变深度
- **Memphis Pop**：几何图案 + 大胆配色
- **Risograph Zine**：双色调印刷 + 手工感

每一种风格都对应一套完整的设计系统，不是简单的“换个背景色”。

### 6. 本地运行 + 自带 Agent

PPT Master 已经在 Kimi Code 等平台上被封装成了一个**即用型 Agent**。你不需要本地部署，直接在支持该 Agent 的 AI 工具里就能调用。

如果你选择本地运行，所有数据都留在你自己的机器上。没有平台锁定，没有模型锁定。

## 04 ｜典型场景和避坑

**适合谁用？**

- **需要频繁制作演示文稿的职场人/咨询顾问**：把报告、白皮书、会议纪要一键转成可编辑的 PPT，省掉 80%的排版时间
- **对 PPT 质量有要求、不愿意用“模板味”太重的 AI 工具的设计师/产品经理**：生成的 PPTX 可以在 PowerPoint 里精细调整，不是“生成即终结”
- **需要批量生成标准化 PPT 的团队**：配合自己的.pptx 模板，一键批量产出风格统一的演示文稿
- **想用 AI 辅助做 PPT 但不想把数据上传到云端的隐私敏感用户**：本地运行，数据不出机器

**不推荐给谁？**

- **只需要快速生成一个“能看”的 PPT、不需要在 PowerPoint 里继续编辑的用户**：Gamma 或 Tome 可能更快
- **完全不想接触任何技术配置的非技术用户**：虽然 PPT Master 有 Agent 版本可以直接用，但本地部署仍需一定的技术基础
- **需要在手机上生成和编辑 PPT 的场景**：PPT Master 的输出是 PPTX，编辑需要在桌面版 PowerPoint 中完成

## 05 ｜快速上手指南（3 分钟）

PPT Master 的本地运行极其简单，只需要 Python 3.10+。

**第 1 步：克隆项目并安装依赖**

```bash
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
pip install -r requirements.txt
```

**第 2 步：配置 API Key**
在项目根目录创建`.env`文件，填入你使用的 LLM 提供商的 API Key（支持 OpenAI、Anthropic、Kimi 等）。

**第 3 步：运行**

```bash
python run.py
```

按照提示输入你的文档路径或主题，AI 会自动生成一份可编辑的 PPTX 文件。

> **不想本地部署？** PPT Master 已被封装成 Agent，你可以在 Kimi Code 等支持该 Agent 的 AI 工具中直接调用。
