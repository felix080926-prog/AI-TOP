游戏开发里的 AI 编程一直有点尴尬。网页和 App 开发早就用上了 Claude Code、Cursor 这类工具，AI 能直接看代码、改代码、跑测试；但轮到 Unity 引擎，事情就卡住了——AI 生成一段 C# 代码，开发者还得手动复制进编辑器，编译报错再把错误贴回去，来回折腾几轮，效率反而不如自己手写。

问题出在「连接」上。AI 编程工具靠 MCP（模型上下文协议）去调用外部环境，而 Unity 编辑器没有现成接口让 AI 直接操作场景、组件和测试。这个项目把这条路打通了。

**项目地址：**https://github.com/IvanMurzak/Unity-MCP

Unity-MCP 做的事很直接：把 Unity 编辑器变成 AI 能直接操作的环境。装完之后，Claude、Cursor、Windsurf 这些 AI 助手能真正读写场景、改组件、跑测试——在聊天窗口里说一句话，Unity 那边真的动了，不用再复制粘贴。

![AI Game Developer 在 Windows 编辑器里的界面](https://raw.githubusercontent.com/IvanMurzak/Unity-MCP/main/docs/img/editor/ai-game-developer-windows.png)

它最值得说的点有两个。

**一是把 C# 方法变成工具，只靠一行标注。** 项目里任何一个 C# 方法，加一行标注就能挂成 MCP 工具，AI 直接调用。这意味着不必为每个需求手写胶水层，现有的游戏逻辑拿来就能被 AI 操作。而且它不挑模型——Anthropic、OpenAI、微软的模型都能接，没有厂商锁定。

**二是它跑在游戏里，不只是编辑器里。** 多数同类工具只在编辑期帮开发者，这个项目还能在编译后的游戏运行时里接 LLM——NPC 的动态对话、实时调试，都能靠它。也就是说同一套工具，开发时帮着写代码，运行时还能给游戏里塞 AI。

![安装后自动生成 AI Skills](https://raw.githubusercontent.com/IvanMurzak/Unity-MCP/main/docs/img/editor/setup-skills.jpg)

从发布到现在，这个项目已经攒了 4418 Star，最近一天又涨了 677，是 Unity 圈里少见的、真正在持续维护的 MCP 方案。

### 装起来只要几条命令

安装分两步：先装 CLI，再把它装进 Unity 项目。

```bash
# 1. 全局安装 unity-mcp-cli
npm install -g unity-mcp-cli

# 2. 在 Unity 项目里安装 "AI Game Developer" 插件
unity-mcp-cli install-plugin ./MyUnityProject
```

不想用 CLI 的话，也可以直接在 Unity 里用 OpenUPM 装插件：`openupm add com.ivanmurzak.unity.mcp`。装完在编辑器里选一个 AI agent（Claude Code、Cursor、Copilot 都行），打开 Unity 项目就会自动连接并生成对应的 skills。

![AI 连接器窗口](https://raw.githubusercontent.com/IvanMurzak/Unity-MCP/main/docs/img/ai-connector-window.gif)

这套工具适合两类人：已经在用 AI 写代码、但受够在编辑器和聊天窗口之间来回粘贴的 Unity 开发者，装上就能省掉大量搬运时间；以及想做「游戏内 AI」（动态 NPC、实时调试）的团队，它把运行时接入也一并解决了。方向上也说明了一件事——AI 编程工具的下一个战场，正在从通用 IDE 往垂直引擎迁移。
