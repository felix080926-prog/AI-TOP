11 月 9 日，Anthropic 端出了 Claude Fable 5.2 和 Mythos 5.2 两个新模型。官方给出的数字是生成速度提升 30%、API 价格下调 20%，还演示了一组夸张案例：1000 多个子智能体连轴转 8 天，从一个空文件夹开始，写出一套能在笔记本上开机的操作系统；另一组 1000 个 Agent 协作 30 小时，把费马大定理做成了 100% 形式化证明。

热度还没散，另一件事就来了。

发布后几个小时，安全研究员 Pliny the Liberator（elder-plinius）在 X 上宣布，他把 Claude Code 里 Fable 5.2 的完整系统指令和工具定义扒了下来——全文约 95 万字符、7832 行、935KB——直接传到了 GitHub 上的 CL4R1T4S 仓库，还预告 Claude 网页版的提示词随后就到。

![Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2](https://www-cdn.anthropic.com/images/4zrzovbb/website/194adcd839895837f70e79a949b2f95496501d77-1280x1280.jpg)

这不是第一次。Fable 5、Fable 5.1、Opus 5、Opus 4.7……几乎每一代模型发布，几小时内就会有完整的系统提示词出现在同一个仓库里。原因也不复杂：用户看到的是模型的回答，真正决定它能说什么、不能说什么、被要求扮演谁的，是那套从未公开的提示词脚手架。

CL4R1T4S 就是专门做这件事的仓库。

![CL4R1T4S 项目主页](https://opengraph.githubassets.com/8c9cde2f432738f3612f69e68f9da24c7bfa7dd4ab0b742dfca1685ed5a090cf/elder-plinius/CL4R1T4S)

**项目地址：**https://github.com/elder-plinius/CL4R1T4S

仓库里按厂商分目录：Anthropic、OpenAI、Google、xAI、Perplexity、Cursor、Windsurf、Devin、Manus、Replit、MiniMax、Moonshot、Z.ai……收录的是各大模型和 Agent 产品的完整系统提示词、行为规范和工具 JSON 定义。目前 5.19 万 Star、1 万多 Fork，今天一天涨了 732 星，热度基本都来自这次 Fable 5.2 的泄露。

## 扒出来的东西，比想象中具体

翻这些提示词，最直观的感受是：模型不是一个模型，而是「一个模型 + 一整套写给它的规矩」。

拿这次泄露的 Fable 5.2 来说，里面能看到版权红线（禁止复现受版权保护的歌曲、书籍片段，连用 SVG、CSS 画知名角色都不行）、记忆系统的隐私边界（哪些信息永远不落盘）、联网搜索的触发规则（涉及价格、法律、时效信息必须先搜再答），以及安全路由——请求一旦触发高危网络安全或生物领域，后台会自动转给 Opus 4.8 或 Opus 5 来回答。

对做 Agent、写 prompt、做模型评测的人来说，这是难得的一手材料：你能看到模型的「系统级默认行为」长什么样，自己搭 harness 的时候，哪些指令其实早就被写死了。

## 怎么用起来

这个仓库不需要安装，一条命令就能拉到本地：

```bash
git clone https://github.com/elder-plinius/CL4R1T4S.git
cd CL4R1T4S && ls
```

想直接看，打开 GitHub 网页按厂商目录翻即可；想贡献新扒到的提示词，README 里写了流程——提 PR，附上模型名与版本、提取日期和上下文说明，或者直接找 @elder_plinius。

![Anthropic 官方公告配图](https://www-cdn.anthropic.com/images/4zrzovbb/website/b2dab182c77b4ccfd36423470106915b20f676ae-1200x630.jpg)

## 为什么值得关注

它的价值不在八卦，而在于把 AI 行业里最不透明的一角摊开了：我们每天在用的智能体，行为边界是被几百 KB 的文字定义出来的。理解这一点，无论是评估一个模型靠不靠谱，还是给自家产品写系统提示词，都能少走弯路。

而 Anthropic 这边，官方公告对这次泄露只字未提——这已经是它近半年里不知道第几次被 Pliny 光顾了。
