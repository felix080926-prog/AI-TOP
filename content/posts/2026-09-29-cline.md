AI 编程助手这几年冒出来一大堆，但多数都把自己锁死在某个编辑器里——离开 VS Code 就只剩个网页，反过来又只认终端。开发者真正想要的，是一个不管在哪干活都能随叫随到的编程智能体。

Cline 就是冲着这件事来的。它把同一个开源 agent 内核拆成了四种形态：VS Code 插件、JetBrains 插件、命令行工具，还有独立的桌面应用，同一个项目在不同环境里都能接着用。

**项目地址：**https://github.com/cline/cline

![Cline 开源编程智能体](https://cline.bot/cline_og_img.png)

这个仓库已经攒了 6.9 万 Star，最近一天又涨了 785，热度不低。跟很多同类相比，它有两个地方不太一样。

第一，不挑模型。Cline 不绑定任何一家 AI 厂商，Anthropic、OpenAI、Google、OpenRouter 上的 200 多个模型、AWS Bedrock、Azure，甚至 Ollama、LM Studio 这类本地模型都能接。想省钱就挂本地模型，想要效果就上旗舰，同一套工作流不用换工具。

第二，能自己动手改代码、跑命令。它会读懂整个项目的文件结构，做跨文件的协同修改，边改边盯着 linter 和编译报错，缺 import、类型对不上这种问题能在你看到之前就先修掉。它也能直接在终端里执行命令、实时看输出，跑测试、部署、起服务这种长流程，它会在后台盯着，一有报错就接着处理。

![Cline 在编辑器里理解代码库](https://assets.int.cline.bot/assets/videos/optimized/understand-codebase-vs-code-studio-poster.jpg)

另外，Plan 和 Act 两种模式可以切换：Plan 模式先探索代码、问清需求、给出方案，确认后再切 Act 模式执行，每一步改动都要你点头；想更省事也能打开自动批准让它自己跑。它还支持多智能体协作，一条命令就能拉起一个团队分工干活。

## 装起来就一条命令

CLI 一条命令装上：

```
npm i -g cline
```

之后 `cline "跑一下测试并修掉报错"` 就能直接开工，还能接进 CI/CD 做无人值守。想要桌面版，去 cline.bot/desktop 下载 macOS 或 Windows 版；想在 VS Code 里用，去插件市场搜 Cline 装上即可。想拿这个内核做二次开发，装 SDK：

```
npm install @cline/sdk
```

客观说，Cline 不是装完就开箱即用的省心工具，它的能力强弱很大程度取决于你配的模型和喂进去的项目上下文，门槛在于要把代码库和规则讲明白。但如果你已经在用 AI 编程，又希望它不止是一个编辑器插件、而是能贯穿终端、桌面和 CI 的全能 agent，这个项目值得放进技术栈里认真评估。
