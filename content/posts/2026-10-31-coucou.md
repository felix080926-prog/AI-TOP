三天连发四个版本，单日涨 799 星——MacBook 那块一直空着的刘海，最近被一个开源小应用占住了。

10 月 29 日连发 0.5.4 和 0.5.5，10 月 30 日发 0.5.6，今天（10 月 31 日）又发了 0.5.7。GitHub 上单日涨了 799 星，总量 6804。海外几家媒体（LockerGnome、Scale Us 等）都在写它，社交平台上还有一批短视频在传同一个画面：一只小方块从 MacBook 刘海探出头来，替你把 AI 编程助手的确认按钮点了。

这个项目叫 coucou，MIT 协议开源。

## 问题卡在"确认"这两个字上

Claude Code、Codex、Cursor、Gemini CLI 这些编程代理，跑长任务时最浪费时间的不是算力，是它卡在一句「要不要允许执行这条命令」上等你——而那个确认入口，一直埋在终端里。人切去开个会、刷会儿网页，代理就干等着；等回来发现它已经卡了二十分钟，什么也没干。

coucou 的做法很直接：把审批从终端里搬出来，搬到永远可见的地方——Mac 的刘海、iPhone 的锁屏和灵动岛。

**项目地址：**https://github.com/Louis-CFM/coucou

![Claude Code 会话在 Mac 刘海里逐条展开](https://raw.githubusercontent.com/Louis-CFM/coucou/HEAD/docs/media/claude-code.png)

## 刘海里的那个小家伙

coucou 的核心是一个叫 Mochi 的角色，住在刘海里（Windows 和 Linux 上则是屏幕顶边的一条）。它不是装饰：每个 agent 会话都是一颗独立的「药丸」，实时显示它在读哪个文件、改了什么，连 +N −M 的行数都标出来，点开能看完整 diff。会话跑完，Mochi 会跳一下；一直没动静，它就缩回去，鼠标扫过才探头。

真正解决痛点的是审批。Claude Code 的权限请求直接弹在刘海上，Allow / Deny / Always 三个按钮一点就走；Claude 的多选问题也能在刘海回答，不想在刘海回就点「Reply in terminal」退回命令行。Codex 同样支持 Allow / Deny。

把 Mac 合上锁屏走人，Mochi 会跟到 iPhone 上：锁屏和灵动岛显示当前最紧急的那个会话，批准用 Face ID。同步走的是你自己的 iCloud，会话里的项目名、命令和问题都用你的 iCloud 密钥加密，没有账号，也没有埋点；密钥存在系统钥匙串里。Android 那边也有人接了个客户端，批准用指纹。

![Mac 锁屏后 Mochi 跟到 iPhone 锁屏上，等你的 Deny / Allow](https://raw.githubusercontent.com/Louis-CFM/coucou/HEAD/docs/media/iphone-live-activity.jpg)

覆盖的 agent 名单也够长：Claude Code、Codex、Cursor、Gemini CLI、Antigravity、Copilot CLI、OpenCode、Amp，还有 Hermes——不绑死一家，任何 agent 打个 hook 标记就能有自己的药丸。

## 这两天更新的两件事

10 月 30 日的 0.5.6 加了个挺实用的开关：聊天可以直接走你自己已经付过钱的 AI 订阅（Claude Code、Antigravity CLI、Gemini CLI、Codex CLI、Cursor CLI、Copilot CLI 的官方命令行工具，用你自己的账号登录），不用再单独配 API key。

今天发的 0.5.7 把 Apple Mail 搬进了刘海：搜索框支持 `from:`、`subject:` 这类写法，能直接读信、标记已读/重要/垃圾，还能让聊天按规则自动分类，配了 Undo。再往前一天的 0.5.4 是纯粹的修 bug 版本——25 个修复全部来自社区提交，其中一条是「hook 服务连不上一次就彻底罢工」，正好是这类工具的命门。

## 装起来就两行命令

macOS 走 Homebrew 最省事：

```bash
brew tap louis-cfm/coucou https://github.com/Louis-CFM/coucou
brew install --cask coucou
```

也可以直接从 Releases 页面下载 `Coucou.zip`，解压后把 Coucou.app 拖进 `/Applications`。要求 macOS 15 或更新；Windows 和 Linux 各有一份，装在屏幕顶边。装完在设置里给对应的 agent 装上 hooks 就行——coucou 动手前会先备份 `~/.claude/settings.json`，并把改动 diff 给你看。想先看看效果，设置里的 Demo 模式会演一遍完整的 Claude Code 会话和权限请求，不往磁盘写任何东西。

## 为什么值得关注

一是它按「失败也要放行」来设计：coucou 没运行时，hook 脚本立刻退出，不会把 Claude Code 卡住——把工具挂到 agent 的 hook 上，这条是底线。二是本机原生，macOS 那份是零第三方依赖的 Swift/SwiftUI 应用，没有遥测，只跟你自己接的服务说话。

更值得注意的是方向。作者在 README 里写了一句挺有意思的话：有些工作室展示了漂亮的刘海伴侣，却从不让任何人用——所以他做了开源版。从 9 月 27 日第一次发版到今天，这个项目已经迭代了 30 个版本，最近三天更是天天在发。AI 编程代理越来越多、跑得越来越久，确认这一步迟早要从终端迁到「眼睛本来就在的地方」，coucou 是这条路上跑得最快的一个——这种速度本身就是信号。
