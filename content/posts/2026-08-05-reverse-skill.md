**大家好，我是雷达君。**

说出来你可能不信：上个月我一个做安全的朋友花了整整三天，就为了在 Kali 虚拟机里配一套顺手的环境——装 Burp Suite、调代理、搭沙箱、写自动化脚本。三天之后他跟我说了一句话："光环境就耗掉一半精力，真正挖洞的时间连 20% 都不到。"

这基本上是安全从业者的日常。渗透测试、逆向分析、CTF 竞赛，每一项都需要一个庞大的工具链。更头疼的是，每个目标环境不一样，每次都得重新调整配置。你现在用 AI 编程助手写代码很爽对吧？但一到安全领域，Claude Code 和 Cursor 就变成了只会写 Python 脚本的"偏科生"——它们根本不知道什么是 Nmap、什么叫 SQL 注入、什么是反汇编。

**reverse-skill 的出现，把这个局面彻底打破了。** 它是一个专门为 AI 编程客户端打造的"安全技能路由包"——简单说，就是把逆向工程、渗透测试、安全研究所需的全部工具链和知识体系，打包成 AI 能直接调用的技能模块。你只需要在 Claude Code 或 Cursor 里说出你的安全需求，它就会自动路由到正确的工具、自动安装缺失的依赖、自动记录操作经验，像一个随身携带的资深安全研究员。

## 01 ｜核心逻辑

reverse-skill 本质上是一个 **"三层路由架构"** ——它不是在 AI 客户端外面套了个壳，而是深入到了 AI Agent 的工具调用层面。

第一层是**意图识别路由**。当你对 AI 说"帮我分析这个二进制文件有没有后门"或者"扫描这个 Web 应用的 SQL 注入点"，reverse-skill 会首先判断这属于哪个安全子领域——逆向、Web 渗透、密码学、还是取证分析。这一步决定了后续工具链的走向，相当于一个安全领域的"智能分诊台"。

第二层是**按需自举工具链**（on-demand toolchain bootstrapping）。这是它最巧妙的设计。reverse-skill 不会预先装好几百个工具占你硬盘，而是根据任务类型，动态拉取并配置所需的工具。需要反汇编？它自动调 Ghidra/IDA 的接口。需要抓包改包？它启动 Burp Suite 的 MCP 服务。需要在沙箱里跑恶意样本？它启动 CTF-Sandbox-Orchestrator 隔离执行。整个过程对用户透明——你只看到结果，看不到背后的调度。

第三层是**自进化经验库**。每次操作都会被记录为结构化的"安全案例"，包括输入的命令、工具的输出、遇到的问题和最终解决方案。下次遇到类似场景，AI 会优先查经验库，而不是从头摸索。三个月跑下来，你的 AI 会从一个只会翻文档的新手，进化成一个见过几百种漏洞的老兵。

## 02 ｜硬核功能盘点

> 🔗 GitHub 地址：https://github.com/zhaoxuya520/reverse-skill

- **Burp Suite MCP 全集成**：reverse-skill 内置了完整的 `burp-mcp-full` 模块，通过 Model Context Protocol 把 Burp Suite 的所有能力（拦截、重放、扫描、Intruder）暴露给 AI。你现在可以直接对 Claude Code 说"拦截这个登录请求，试试 TOP 100 弱口令爆破"，它会自己操作 Burp，不用你手动点任何按钮。

- **CTF 沙箱编排器**：`CTF-Sandbox-Orchestrator` 是一个专门为安全研究设计的隔离执行环境。逆向二进制文件、运行可疑脚本、测试漏洞利用代码，全在沙箱里完成。更重要的是它支持"快照回滚"——搞崩了环境？一键恢复到初始状态，省去重装虚拟机的痛苦。

- **Kali 工具链自动装配**：内置了 Kali Linux 完整工具集的索引和自动安装脚本。你不需要自己维护一个 Kali VM，reverse-skill 会根据任务按需拉取对应工具（nmap、sqlmap、metasploit、john、hashcat 等），并在隔离环境中运行。换句话说，你的 MacBook 也能"变成"一台 Kali。

- **AI 客户端全兼容**：目前支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端。架构上采用了"适配器模式"，每个客户端的工具调用协议不同，但 reverse-skill 在最上层抽象了一个统一接口。新增客户端只需写一个适配器，不用改核心逻辑。

- **安全报告自动生成**：`reports` 模块支持自动生成结构化的渗透测试报告。发现漏洞 → 记录复现步骤 → 评估危害等级 → 给出修复建议，一条龙输出 PDF。做过安服的都知道，写报告往往比挖洞还耗时，这个功能直接省掉了一半工作量。

## 03 ｜典型场景和避坑

**典型场景一：Web 应用渗透测试**

假设你拿到一个授权渗透测试的目标网站。传统做法：开 Burp → 配浏览器代理 → 手动爬一遍 → 对每个接口逐一测 SQL 注入 / XSS / CSRF → 手动记笔记 → 写报告。全程至少 4-6 小时。用 reverse-skill：在 Cursor 里输入"对 target.com 做完整 Web 渗透测试"，AI 会自动启动 Burp MCP、配置扫描策略、跑完所有注入点、把漏洞按严重度排序，最后生成一份带截图和修复建议的报告。你只需要在关键步骤做人工确认。

**典型场景二：CTF 逆向赛题快速求解**

CTF 比赛里时间就是排名。拿到一个二进制文件，要先查壳、反汇编、定位关键函数、分析加密算法、写解密脚本。reverse-skill 的"逆向技能链"可以一步触发整个流程：查壳 → 自动选反汇编器 → 定位 main 函数 → 提取加密常量 → 生成 Python 解密脚本 → 在沙箱里验证。原本需要 30 分钟的分析流程，压缩到 5 分钟以内。

**避坑指南**

- 第一，**永远只用于授权测试**。reverse-skill 的能力很强，但它的设计前提是"合法合规"。对未授权的目标使用渗透测试功能，不仅违法，而且工具本身的日志和网络请求会留下完整证据链。请确保你已获得书面授权再动手。

- 第二，**沙箱不是万能的**。CTF-Sandbox-Orchestrator 提供了隔离执行环境，但它毕竟是容器级别的隔离，不是硬件级。分析高危恶意样本（如勒索软件、内核 Rootkit）时，建议在独立的物理隔离设备上操作，不要把宿主机的安全寄托在一个 Docker 容器上。

- 第三，**AI 的判断不能替代人工经验**。reverse-skill 可以大幅提升效率，但 AI 对漏洞的"理解"是模式匹配，不是真正的逻辑推理。它可能误报（把正常功能标为漏洞），也可能漏报（复杂逻辑绕过了检测规则）。所有 AI 输出的结果，都需要有经验的安全工程师复核。

## 04 ｜上手教程

环境要求：Node.js 18+、Docker（用于沙箱）、任一款支持的 AI 编程客户端。

```bash
# 1. 克隆仓库
git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill

# 2. 安装核心依赖
npm install

# 3. 初始化技能路由表（这一步会下载索引，不装具体工具）
npm run init

# 4. 配置你的 AI 客户端
# 以 Claude Code 为例，将技能文件链接到 Claude Code 的 skills 目录：
ln -s $(pwd)/skills/* ~/.claude/skills/

# 5. 测试：在 Claude Code 中输入
# "用 reverse-skill 扫描 localhost:3000 的开放端口"
```

对于 Cursor / Kiro / Cline 用户，项目 `docs/` 目录下有各平台的分步配置指南。整个初始化流程不超过 5 分钟。首次执行安全任务时，reverse-skill 会自动下载对应工具（如 nmap、sqlmap），后续任务直接用缓存。

**高级玩法**：如果你有自己的安全工具集，可以在 `skills/` 目录下创建自定义技能文件（YAML 格式），定义工具路径、触发词和输出解析规则。经验库会自动收录这些自定义技能的执行记录，让 AI 越用越顺手。

## 05 ｜总结

reverse-skill 做的事情，本质上是把安全从业者的"肌肉记忆"编码进了 AI 系统。那些你做了几百遍的操作——开 Burp、配代理、跑扫描、看结果、写报告——现在变成了 AI 的一个技能调用。这不是替代安全研究员，而是让他们从重复劳动中解放出来，把精力放在真正需要创造力的环节：漏洞利用链的设计、新型攻击面的探索、复杂业务逻辑的审计。

当然，这个项目还很年轻。114 个 commit、6 个 open issue，说明它还在快速迭代期。目前的工具覆盖面集中在 Web 渗透和二进制逆向，移动端安全、云安全、车联网安全等领域暂时还是空白。但它的架构设计非常有远见——"适配器 + 路由 + 自举 + 经验库"，这套模式可以横向扩展到任何安全子领域。

当越来越多的安全工程师把自己的经验编码成技能文件、贡献到经验库，reverse-skill 会从一个人的工具箱，变成一个安全社区的集体智慧。那一天到来的时候，"配环境花两天"的日子就真的翻篇了。
