上个月收到 Claude 的续费提醒，20 刀。

我盯着那个数字想了半天：这钱花得值吗？然后我关掉自动续费，装了一个叫 qwen-code 的东西。两周用下来，说实话，有点后悔没早点换。

qwen-code 是 Qwen 团队开源的 AI 编程 agent，住在终端里。

敲一个 qwen，它就在你眼皮底下干活：看代码、改 bug、跑测试、写 PR，一条龙。跟 Claude Code 是同一个物种，但它有两个地方特别戳我。上 GitHub 一看，2.7 万 star，今天一天又涨了近 800。

**项目地址：**https://github.com/QwenLM/qwen-code

![Qwen Code 终端界面](https://img.alicdn.com/imgextra/i2/O1CN01K0nwj41RM1Il8kB0t_!!6000000002096-2-tps-1544-1060.png)

## 上手只要两步

第一步，安装，一条命令的事：

```bash
curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen-standalone.sh | bash
```

第二步，敲 qwen 启动，输入 /auth 填个 API key。

关键是，这个 key 不一定是 Qwen 的。OpenAI、Anthropic、Gemini 的 key 它都认，本地跑 Ollama、vLLM 也没问题。想彻底不花钱，就用 Qwen 官方开源的模型。

框架开源，模型也开源。没有哪一环把你锁死，想走随时能走。

## 比我想象的能打

我原本以为平替会缺胳膊少腿。用了几天发现，Claude Code 有的它基本都有：SubAgents、Auto-Memory、Auto-Skills、Plan Mode、沙箱、git worktree……

有两个功能我在别家没见过。

一个是会话能接上。半夜退出终端，第二天回来，它记得昨天干到哪了，敲一条命令直接续上，不是重新开始。

![会话退出后自动留痕，回来一键续上](https://raw.githubusercontent.com/QwenLM/qwen-code/main/.github/assets/exit-resume-echo/02-pr-exit-echo.png)

另一个是「不止终端」。VS Code、JetBrains、Zed 都有插件，还有桌面版和网页版 Shell。更离谱的是 IM bot：接上飞书、微信、钉钉、Telegram，你在聊天窗口里 @ 它一下，它就去写代码，写完把结果贴回来。

![网页端 Shell 里也能接着用](https://raw.githubusercontent.com/QwenLM/qwen-code/main/docs/assets/workspace-display-name-web-shell.jpg)

还有个 Agent Arena 我也喜欢：让好几个模型在同一个任务上对打，谁行谁上，挑模型不用再靠玄学。

## 一个让我放心的细节

qwen-code 这个项目自己，就是用它自己在开发。

翻它的仓库能看到：提 issue、交 PR、review 代码、跑测试，全是它自己的 agent 干的。敢拿自己当小白鼠的工具，用起来踏实。

想试的话，今晚就能用上。装完敲 qwen，/auth 填个 key，让它先帮你修一个 bug——你就回不去了。
