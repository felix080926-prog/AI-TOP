**大家好，我是雷达君。**

你有没有经历过这种场景：你同时用着 Claude Code、Cursor、Codex，每个工具都有自己的配置、自己的 MCP、自己的技能。你费了好大劲在 Claude Code 里配好了一套工作流，换到 Cursor 里想复用，又得从头折腾一遍。

更扎心的是，Anthropic 出了一个叫**Claude Cowork**的桌面应用，号称能让 AI 操作你的电脑、自动化日常工作。功能确实香，但门槛也不低——只有 Anthropic 的 Max 用户才能用，最低每月 100 美元。

如果你不舍得每月花 100 美元订阅费，但又想要一个能跑同样事情的桌面 AI 助手呢？

今天雷达君要安利的这个开源项目，就是来填这个坑的。它是一个免费、开源、跨平台的 AI Agent 桌面应用——Claude Cowork 和 Codex 的终极平替。

它就是——**OpenWork**。

## 01 ｜核心逻辑：一个 App，管住你所有 AI 工具

OpenWork 的核心理念可以用一句话概括：**把你所有 AI Agent 的工具、技能、MCP，全部塞进一个桌面 App 里统一管理**。

你平时是不是在多个 AI 工具之间来回切换？Claude Code 里配了一套 MCP，Cursor 里又配了一套，Codex 里还得再来一遍。每次切换工具，都要重新配置一遍环境。更麻烦的是，你在一个工具里写好的自动化工作流，换到另一个工具里就用不了了。

OpenWork 的做法很直接：**你只需要在 OpenWork 里配置一次——MCP、Skills、LLM 提供商、连 Google Workspace 和 Microsoft 365——然后所有 AI 工具（Claude Code、Cursor、Codex、Gemini 等）都可以通过 OpenWork 的 MCP 协议复用同一套能力**。

它本质上不是一个“AI”，而是一个**AI 工具的中控台**。你不必放弃你正在用的 AI 编程工具，只需要给它们加一个“OpenWork MCP”，所有能力就能共享。

**更厉害的是，OpenWork 不止是一个“配置管理器”，它自己就是一个完整的桌面 AI 助手**。你可以直接在 OpenWork 的桌面 App 里跟 AI 对话，让它帮你操作电脑、处理文件、自动化日常工作。

**一句话：Claude Cowork 收费 100 美元/月，OpenWork 免费开源，还让你所有 AI 工具共享同一套能力**。

## 02 ｜硬核功能盘点

> 🔗 **GitHub 地址**：https://github.com/different-ai/openwork

### 1. 一个 MCP，打通所有 AI 工具

这是 OpenWork 最核心、最拉开差距的能力。

你在 OpenWork 里配置好 Skills、MCP 连接、Google Workspace 和 Microsoft 365 之后，只需要在所有 AI 工具里添加一个**OpenWork MCP**，它们就全部共享同一套能力了。

```bash
# Claude Code
claude mcp add --transport http openwork https://api.openworklabs.com/mcp/agent

# Codex
codex mcp add openwork --url https://api.openworklabs.com/mcp/agent
```

OpenWork MCP 暴露了两个核心工具：`search_capabilities`（查找你能用什么）和`execute_capability`（执行它）。你的 AI 助手不需要知道背后怎么实现的，只需要调用这两个工具就行。

**你配置一次，所有 AI 共享**。

### 2. 开箱即用：2 分钟上手，5 个免费模型

很多开源 AI 工具号称“免费”，但你得花一个周末配置环境。OpenWork 不是这样。

它开箱自带一个叫**OpenCode Zen**的模型提供商，默认就有**5 个免费模型**可以用——DeepSeek V4 Flash、Qwen3.6 Plus、MiniMax M2.5 等。不需要绑信用卡，不需要订阅，下载 App 就能用。

有开发者实测：用 OpenWork + DeepSeek V4 Flash 跑一个代码重构任务，生成 diff、应用修改、测试全绿——**在 Claude Cowork 里同样的任务需要\$20/月的订阅**。

**零配置、零订阅、立即可用。**

### 3. MCP 一键连接：告别 JSON 配置文件

如果你在 Claude Cowork 里配过 MCP，你大概知道有多痛苦——打开 JSON 配置文件、找到正确的格式、粘贴服务器命令、重启、祈祷它能加载。有开发者统计过，第一次配 5 个 MCP 工具大约需要**20 分钟**。

OpenWork 把这件事做成了一个**带 Connect 按钮的卡片**。Notion、Linear、Sentry、Stripe、Context7——点一下、OAuth 授权、完成。5 个 MCP 全部配完，**不到 3 分钟**。

**没有 JSON 配置文件，只有点一下和点两下的区别。**

### 4. 真正的“AI 操作电脑”：能点能按能打字

OpenWork 最让人眼前一亮的能力，是**UI Control**——AI 可以直接操作你的桌面应用。

你输入“打开 Settings，然后切换到 Appearance”，AI 会真的打开设置面板、切换标签页——全程不需要你动鼠标。这听起来像噱头，但当你亲眼看到它在你刚安装的软件上跑起来时，感受是完全不一样的。

> **现实摩擦提醒**：UI Control 功能目前在**OpenCode Zen 模型**上工作得最好。换到 Gemini Flash 等模型时，它会回退到浏览器工具而不是直接操作原生 UI。

### 5. 本地优先 + 云端就绪

OpenWork 是**本地优先**的——跑在你自己的机器上，数据留在本地。但它也支持远程连接：你可以在云端启动一个 Worker，然后用桌面 App 连过去。

它提供了三种使用方式：

- **桌面 App**：完整功能，双键启动
- **CLI Orchestrator**：无头模式，适合服务器
- **Slack/Telegram 连接器**：在聊天软件里用

**从个人到企业，从本地到云端，全场景覆盖。**

### 6. 企业级能力：OpenWork Den

对于团队和企业，OpenWork 提供了**OpenWork Den**——一个控制平面。你可以：

- 统一配置推理服务和模型提供商权限
- 邀请团队成员、创建团队、统一管理访问
- 发布技能和插件到内部市场
- 控制桌面策略、限制本地模型访问

**一个小团队也能用上企业级的 AI 治理能力。**

## 04 ｜典型场景和避坑

**适合谁用？**

- **同时使用 Claude Code、Cursor、Codex 等多个 AI 工具的开发者**：一个 OpenWork MCP 让所有工具共享同一套配置
- **想用 AI 自动化日常电脑操作但不想付订阅费的个人用户**：免费、开源、开箱即用
- **需要在团队内共享 AI 工作流的团队**：OpenWork Den 提供统一管理和分发能力
- **想从 Claude Cowork 迁移出来的付费用户**：同样的桌面 AI 体验，价格从\$20/月降到 0

**不推荐给谁？**

- **只需要纯终端 CLI、完全不需要桌面的极简主义者**：直接用 OpenCode CLI 可能更轻量
- **Windows 用户且不想付费**：Windows 版目前需要通过付费支持计划获取
- **完全不想接触任何技术配置的纯小白**：虽然比同类工具友好得多，但仍需一定的技术基础

## 05 ｜快速上手指南（3 分钟）

OpenWork 的安装和使用极其简单，下载就能用。

**第 1 步：下载安装**

访问 [openworklabs.com/download](https://openworklabs.com/download "openworklabs.com/download") 下载对应平台的安装包：

- macOS：直接下载 DMG
- Linux：下载 DEB 包
- Windows：通过付费支持计划获取

> ⚠️ **Windows 用户特别提醒**：安装前需要先安装 Node.js。如果 UI Control 功能崩溃，通过任务管理器强制关闭 OpenWork 再重新启动即可修复。

**第 2 步：打开 App，开始使用**

安装后打开 OpenWork，你会看到一个简洁的聊天界面。默认已经内置了**5 个免费模型**可以直接用：

- DeepSeek V4 Flash
- Qwen3.6 Plus
- MiniMax M2.5
- 还有两个更多免费模型

**不需要绑信用卡、不需要订阅，开聊就能用。**

**第 3 步（可选）：接入你已有的 AI 工具**

如果你想让你正在用的 Claude Code、Cursor 或 Codex 共享 OpenWork 的能力：

```bash
# Claude Code
claude mcp add --transport http openwork https://api.openworklabs.com/mcp/agent

# Codex
codex mcp add openwork --url https://api.openworklabs.com/mcp/agent
```

添加完成后，你的 AI 工具就能使用 OpenWork 里配置的所有 Skills、MCP 和连接服务了。

**不想装桌面 App？** 也可以用 CLI 版本：

```bash
npm install -g openwork-orchestrator
openwork start --workspace /path/to/workspace --approval auto
```
