上周我想做个「自动读邮件、提取重点、同步到 Notion」的小工具。

本来准备老老实实写 LangChain，把模型、向量库、工具调用一个个串起来。写到三百多行的时候，我突然不想写了。

全是胶水代码。一堆重复的鉴权、回调、错误处理。

然后我打开了 Langflow。

**项目地址：**https://github.com/langflow-ai/langflow

![Langflow 拖拽式工作流构建界面](https://www.langflow.org/images/drag-drop-deploy.png)

它做的事特别简单：把「搭 AI 应用」变成在画布上拖拽连线。模型调用是一个方块，向量检索是一个方块，工具调用也是一个方块。把这些方块拖出来，用线连上，一条 AI 工作流就搭好了。

不用写那堆胶水代码。

## 上手只要两行命令

装它比我想象的简单。有 uv 的话，两行就够：

```
uv pip install langflow -U
uv run langflow run
```

浏览器会自动打开 localhost:7860，画布就在那儿。懒得配环境，也有桌面版，Windows 和 Mac 都有，下载双击就能用。

我以前总觉得可视化工具是「玩具」，搭个 Demo 行，真上生产就露馅。结果它内置了 LangChain 的组件库，两百多个现成节点，模型、数据库、搜索、API 全封好了。

最关键是每个节点都能单独跑一下测试，哪一步输出不对，一眼就看出来，不用对着满屏报错猜原因。

![Langflow 运行与协作界面](https://www.langflow.org/images/run-share-collab.png)

## 最惊喜的部分

最让我意外的是「导出」。画布上搭好的流程，能一键导出成标准 API，或者直接部署成 MCP server，丢给别的应用当工具用。

也就是说，你在画布上拖出来的东西不是只能自嗨，是真能上线跑。

我搭那个「读邮件 → 提取信息 → 写进 Notion」的流程，从头到尾不到半小时。换以前，光是把邮件、LLM、Notion 三个 API 的鉴权和错误处理写明白，半天就没了。

现在就是拖几个方块，连几条线，点一下 Run，完事。

![Langflow 一键导出 API 与部署](https://www.langflow.org/images/dialog-api.png)

这东西在 GitHub 上已经十五万 Star，今天又涨了七百多。用它的人多，社区活跃，现成的模板和流程一抓一大把，很多场景直接抄别人的改改就能用。

想试试的话，pip 装一下，画布打开就能开始拖。
