10 月 21 日，Anthropic 发布了它的"个人 AI 代理"——Claude Duet，一个会主动来找你的助手：每天早上发一份待办简报，盯着你连的各种应用，只在需要你注意时才发消息，动手之前先问你一句。研究预览版当天开放 waitlist，先给美国的 Pro 和 Max 订阅用户，跑在 Opus 5.5 上，iOS、Android、Web 各有一个独立入口。

![Claude Duet 官方发布页配图](https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png)

这件事本身不算新鲜——OpenAI 有 Dots，Meta 有 Muse，现在 Anthropic 也下场了。几家大厂抢的是同一个东西：一个能替你干活、又不会乱来的"主动式 AI 代理"。区别在于，这些产品全都跑在别人的服务器上，你的记忆、凭证、日程，都存在厂商手里。

所以开源社区的反应很快。Claude Duet 发布不到一天，Open Duet 就冲上了 GitHub Trending——一个自托管、开源的"AI 同事"工作台，把 Duet 那套思路用你自己能跑起来的方式重做了一遍，Apache-2.0 协议，发布到现在已经攒了 6000 多 Star，单日涨了 619。

![Open Duet 演示视频截图](https://i.ytimg.com/vi/MzgrNQXgVX4/maxresdefault.jpg)

**项目地址：**https://github.com/Anil-matcha/open-duet

Open Duet 干的事和 Duet 是同一个方向，做法却完全不同。它给你的是**有名字的 AI 同事**：每个 agent 有自己的职位、指令、记忆和工作目录，还有一台隔离的电脑——跑命令、改文件都在独立的 Docker 容器里，炸不到你的主机。最核心的一道闸门是**审批**：任何有风险的动作（写文件、跑命令）都会先弹出一张卡，写清楚它要干什么，你点 Allow 才会执行，还能存成规则、随时撤销。

它的记忆不是聊天记录那种短命的东西。每个 agent 维护一份 MEMORY.md 和主题笔记，跨对话还能想起来，支持撤销。routines 可以按 cron、每周、间隔或 webhook 定时跑，有运行历史、漏跑追踪和重启恢复。前端是网页、桌面 app、Telegram 三个入口共用一个 API，凭证加密存在 PostgreSQL（或实验性的 SQLite）。

装起来也不复杂，桌面版就三条命令：

```bash
git clone https://github.com/Anil-matcha/open-duet
cd open-duet/desktop
npm run app
```

`npm run app` 第一次会自动完成初始化，用本地 SQLite，不需要配 .env。想在服务器上常驻、让 agent 在你合上笔记本之后继续干活，也可以走 `python -m app.server` 或 Docker compose，官方文档里都写清楚了。

要说它比闭源版强在哪，一句话：**数据主权和可见性**。闭源产品的 agent 是个黑盒，它替你做决定，但你看不到中间过程；Open Duet 每一步工具调用都能点开看，审批日志有据可查，模型也不锁定——Claude、Codex、任何 ACP CLI 或 OpenAI 兼容端点都能接，额度用完了还能自动切到别的引擎。

它还不是 Duet 的完全替代：团队协作、agent 之间互相委派、更多应用连接器都还写在 roadmap 上，官方也明说了先读已知限制再给别人用。但作为一个能自己审计、自己掌控数据的 AI 同事底座，Claude Duet 发布当天就有开源版顶上来，这件事本身就说明——主动式 AI 代理这条赛道，开源的跟进速度已经和闭源咬得很紧了。
