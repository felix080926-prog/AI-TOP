**大家好，我是雷达君。**

你有没有过这样的冲动：在 QQ 群里@一个 AI，它能帮你查资料、写代码、画图、甚至陪你聊天解闷？或者在微信里有一个 24 小时在线的智能助理，你说句话它就帮你把事办了？

OpenClaw 能做到，但它的配置门槛把很多人挡在了门外。

今天雷达君要安利的这个开源项目，就是来搞定这件事的。它把 AI Agent 塞进了 QQ、微信、飞书、钉钉、Telegram、Discord 等**十几种主流 IM 平台**——装好就能用，配置简单到你想哭。

它就是——**AstrBot**。

## 01 ｜核心逻辑：一个 AI，塞进所有聊天软件里

AstrBot 的核心理念可以用一句话概括：**把你所有聊天软件里的 AI，统一成一个“人”。**

你平时是不是在 QQ 群里聊天、在微信里沟通工作、在飞书和钉钉上开会？每个平台都有自己的生态，AI 也散落在不同的工具里——ChatGPT 在网页上，Claude 在 App 里，你那个用 Python 写的自动回复脚本只跑在 QQ 上。

AstrBot 做的事很简单粗暴：**一个 AI 后端，同时接入所有平台**。你配置好一次模型和功能，它就能同时在 QQ、微信、飞书、钉钉、Telegram、Discord、Slack、LINE 等十几个平台上“分身”出现。

你在 QQ 群里@它问天气，它在飞书里帮你记会议纪要，在微信里回你朋友的消息——**同一个 AI，同时做不同的事，不用每个平台单独搭一套。**

**一句话：OpenClaw 把 AI 连到不同渠道，AstrBot 把 AI 塞进不同平台。**

## 02 ｜硬核功能盘点

> 🔗 **GitHub 地址**：https://github.com/AstrBotDevs/AstrBot

### 1. 十几种 IM 平台全支持：QQ、微信、飞书、钉钉，一个不落

这是 AstrBot 最核心、最拉开差距的能力。它支持的平台清单长得像一份社交 App 列表：

- **国内主流**：QQ（官方 OneBot v11 协议）、企业微信、微信公众号、飞书（Lark）、钉钉
- **国际主流**：Telegram、Discord、Slack、LINE
- **更多社区支持**：KOOK、Misskey、Mattermost、Matrix、Rocket.Chat、VoceChat

你不用为了不同平台分别写不同的机器人代码。一个 AstrBot 后端，通吃所有平台。

### 2. 1000+插件：想要什么功能，点一下就行

AstrBot 的插件生态非常成熟，**已有超过 1000 个社区插件可一键安装**。从查天气、搜资源、做翻译，到接入 Dify、阿里云百炼、Coze 等 AI 平台，全部点一下就能用。

如果你有特殊需求，AstrBot 提供了完整的插件开发框架。自己写一个插件，打包上传到社区，别人也能用。

### 3. Agent 沙箱：AI 写的代码，跑在“笼子”里

让 AI 直接在服务器上执行代码？听起来很危险。万一它跑了个`rm -rf /`怎么办？

AstrBot 提供了**Agent 沙箱（Agent Sandbox）** ——AI 执行的代码、Shell 命令全部在隔离环境里运行。它“闯祸”的范围是可控的，不会把你的服务器搞崩。

### 4. 角色扮演 + 情感陪伴：不只是工具，还是“朋友”

AstrBot 不只是一个“干活”的工具。它内置了**角色扮演（Role-playing）和情感陪伴（Emotional Companionship）** 能力。你可以给 AI 设定一个人设——比如“一个毒舌的程序员”或“温柔的心理咨询师”——它会按照这个人设跟你聊天。

**它能理解情绪、提供真实的陪伴，同时可靠地完成任务**。

### 5. WebUI + 桌面 App：不用敲命令也能用

AstrBot 提供了完整的**WebUI 管理界面**，所有配置、插件管理、对话记录都在浏览器里完成。它还提供了**桌面 App**和**Launcher 启动器**，适合不想折腾命令行的用户。

### 6. 模型自由：想用哪个用哪个

AstrBot 支持几乎所有主流 LLM：

- OpenAI、Anthropic Claude、Google Gemini
- 国内厂商：DeepSeek、智谱 AI（Zhipu AI）、月之暗面（Moonshot AI）
- 本地模型：Ollama、LM Studio
- 平台接入：Dify、阿里云百炼、Coze
- API 网关：AIHubMix、302.AI、SiliconFlow 等

它还支持**语音服务**——Whisper、SenseVoice 做语音转文字，OpenAI TTS、Azure TTS、Edge TTS 等做文字转语音。

## 03 ｜ AstrBot vs OpenClaw（龙虾）

既然 AstrBot 的 README 里写着“can be your openclaw alternative”，我们不妨把这两个项目放在一起比一比：

| 维度             | **AstrBot**                     | **OpenClaw（龙虾）** |
| :--------------- | :------------------------------ | :------------------- |
| **核心定位**     | AI Agent 全能助理平台           | AI Agent 万能连接器  |
| **国内 IM 支持** | ✅ QQ、微信、飞书、钉钉原生支持 | ⚠️ 需手动配置        |
| **插件生态**     | ✅ 1000+插件一键安装            | ⚠️ 依赖社区          |
| **Agent 沙箱**   | ✅ 原生支持                     | ❌                   |
| **角色扮演**     | ✅ 原生支持                     | ❌                   |

| **部署难度**     | ⭐⭐ 极低（uv 一键安装）        | ⭐⭐⭐⭐ 较高        |

| **Star 数**      | 6.6K                            | 37 万                |

**简单说：OpenClaw 是“把所有渠道连起来”的协议层，AstrBot 是“把所有平台用起来”的应用层**。前者更底层、更灵活，后者更完整、更易用。

## 04 ｜典型场景和避坑

**适合谁用？**

- **想在 QQ 群、微信群、飞书里部署 AI 助理的个人/团队**：一个后端，通吃所有平台
- **想给 AI 设定“人设”做情感陪伴或角色扮演的二次元/虚拟主播爱好者**：原生支持角色扮演
- **不想敲命令行、希望有 Web 界面管理 AI 的普通用户**：WebUI + 桌面 App 全覆盖
- **需要 AI 执行代码但担心安全问题的开发者**：Agent 沙箱提供隔离执行环境

**不推荐给谁？**

- **只需要单平台、单功能的简单场景**：用 AstrBot 属于杀鸡用牛刀
- **完全不需要 IM 平台接入、只做纯 API 调用的后端开发者**：直接调用 LLM API 可能更轻量

## 05 ｜快速上手指南（3 分钟）

AstrBot 的安装极其简单，官方提供了**一键部署脚本**。

**第 1 步：安装 uv（Python 包管理器）**

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**第 2 步：一键安装 AstrBot**

```bash
uv tool install astrbot --python 3.12
```

**第 3 步：初始化配置**

```bash
astrbot init
```

这一步会引导你完成基础配置——选择 LLM 提供商、填入 API Key、选择要接入的 IM 平台。

**第 4 步：启动**

```bash
astrbot run
```

> **macOS 用户注意**：由于 macOS 的安全检查，首次运行`astrbot`命令可能需要等待 10-20 秒。

**不想自己部署？** AstrBot 提供了**RainYun 一键云部署**、**Docker 部署**、**Replit 在线体验**等多种方式。桌面用户还可以下载**AstrBot 桌面 App**。

> **验证安装成功**：运行`astrbot --version`，如果能返回版本号，说明安装成功。

## 06 ｜总结

AstrBot 解决了一个被很多人忽视但真实存在的问题：**AI 应该活在你每天用的聊天软件里，而不是只在浏览器里。**

你用 QQ、微信、飞书、钉钉——你的朋友、同事、客户都在里面。但你的 AI 却住在另一个“平行宇宙”里。你想用 AI 的时候，得切换 App、复制粘贴、来回折腾。

AstrBot 把 AI 从“浏览器”里拽了出来，塞进了你每天打开的聊天软件里。一个后端，同时接入十几个平台，1000+插件一键安装，Agent 沙箱安全执行，角色扮演陪你聊天——它把“AI 全能助理”这件事，从“极客玩具”变成了“普通人也能用的工具”。
