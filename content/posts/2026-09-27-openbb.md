做量化、搞投研、搭金融类 AI Agent 的人，几乎都卡在同一个地方：数据。

股票行情在 A 家，期权链在 B 家，加密货币在 C 家，宏观数据又散在几十个网页里。想把这些喂给一个 AI Agent 之前，先得写一堆爬虫凑齐数据、清洗成统一格式，再想办法让 Agent 能查到。这段「脏活」没有现成工具能一键解决，往往只能自己搭——直到把 Open Data Platform 搬过来。

Open Data Platform（ODP）是 OpenBB 开源的一套数据接入底座，核心思路一句话就能说清：**连接一次，处处消费**（connect once, consume everywhere）。它把专有数据、授权数据和公开数据源整合到一个统一层，再一次性暴露给多个下游：Python 环境给量化研究员，Workspace 和 Excel 给分析师，MCP 服务器给 AI Agent，REST API 给其他应用。

**项目地址：**https://github.com/OpenBB-finance/OpenBB

![OpenBB Workspace 的数据分析界面](https://openbb-cms.directus.app/assets/f69b6aaf-0821-4bc8-a43c-715e03a924ef.png)

## 一个接口，把散落的数据源收拢

真正值钱的是它对 AI Agent 的接入方式。很多金融数据服务收费高、接口又封闭，想接进自己搭的 Agent 工作流得绕一大圈。ODP 通过 MCP 服务器把数据暴露给 AI Agent——MCP 就是 Model Context Protocol，让 Agent 按统一协议查数据的标准。把 ODP 数据后端跑起来，Agent 就能像查字典一样查行情、财报、期权链，不用为每个数据源单独写胶水代码。官方还配套开源了 agents-for-openbb，专门给 Workspace 接 Agent 用。

对量化的人同样省事。一段 `obb.equity.price.historical("AAPL")` 就能把苹果的历史价格拉成 DataFrame，和 pandas 无缝衔接，回测前的脏活基本省掉。股票、期权、加密货币、宏观经济，接进来都是同一种格式。

## 装起来只要几步

Python 环境里一条命令装好核心包：

```bash
pip install "openbb[all]"
```

要起一个给 AI Agent 或其他应用用的数据服务，再跑一条：

```bash
openbb-api
```

这会用 FastAPI 在本地 127.0.0.1:6900 起一个服务，浏览器打开这个地址就能验证接口通了。想用命令行就装 `pip install openbb-cli`，想拿源码折腾就 `git clone https://github.com/OpenBB-finance/OpenBB.git`。

## 谁适合用

项目在 GitHub 已经攒了 7.3 万多个 Star，今天单日又涨了 736，说明「统一金融数据接入」这个痛点是真的普遍。适合的人群很明确：个人量化研究者、独立投研的人、想搭金融 AI Agent 应用的开发者。数据源统一、接口干净、本地可自部署，数据不经过第三方的手。

要说清楚的是，它解决的是「数据接入与统一」这一层，不负责替你对接某些付费实时行情的完整服务，也不是交易下单工具。协议是 AGPLv3，商用前值得看清楚。方向上，把金融数据标准化、再通过 MCP 喂给 AI Agent，这条路径正在成为标配，OpenBB 走在了前面。
