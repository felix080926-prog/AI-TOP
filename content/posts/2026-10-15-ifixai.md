AI Agent 越来越多地被放进真实业务里跑——订票、写代码、处理退款、对接客户。但一个越来越现实的问题是：这些 Agent 通过了评测、跑通了测试，就真的在干该干的事吗？现有的 Eval、红队测试、可观测性工具，大部分还在盯技术指标——token 效率、延迟、有没有被提示词注入。它们回答不了那个最关键的问题：这个 Agent 有没有按业务 KPI 和组织规则，把该干的活干好。

iFixAi 就是冲着这个问题来的。它做的事情很直接：独立审计 AI Agent，人类可以发起，Agent 自己也能发起，120 秒内给出一个明确答案——这个 Agent 到底有没有在做它该做的事。

**项目地址：**https://github.com/ifixai-ai/iFixAi

![iFixAi 官方示意图](https://www.ifixai.ai/opengraph-image.png?opengraph-image.0aywu0gqsuo9-.png)

它和传统评测最大的不同，是审计的方式。iFixAi 把 AI 红队（对抗性测试）和运营保障（Operational Assurance）结合起来，再叠上哲学、伦理、社会学的视角，专门去找 Agent 的"业务语境偏差"——那些动作、遗漏或行为，跟业务想让它做的对不上号的地方。跑完不是一句"好/坏"，而是一个 A-F 的等级加一张打分卡，评分由五个核心支柱构成，报告以 JSON 和 Markdown 落地，可以审计、可以重放。

![iFixAi 连接智能体的引导界面](https://www.ifixai.ai/onboarding/os/connect.png)

它最值得说的一点，是"谁来打分"。评审模型会自动从另一个厂商配对——被测 Agent 自己所在的厂商会被排除，所以永远不会出现"自己给自己打分"的情况。只有当第二个独立厂商来评，这个等级才是"可引用"的。

装起来只要几步。用 pip 装 CLI，带上你要测的厂商 extra：

```bash
pip install "ifixai[openai]"
ifixai setup
ifixai run
```

`ifixai setup` 是个方向键向导，选好 provider、模型、评审模型和套件后写入 `ifixai.yaml`，之后 `ifixai run` 不用再传参数，报告落在 `./ifixai-results/`。默认一次跑 10 项"essential"检查，`--full-run` 跑全部 60 项。不想用 CLI，也可以在 Claude Code 里 `/plugin marketplace add ifixai-ai/iFixAi`，或者一条 `uvx ifixai install` 给任意 Agent 生成原生 `/ifixai-skill` 斜杠命令。

这个项目从发布到现在已经攒了 2.7 万 Star，今天一天又涨了 2100 多。开源引擎免费提供 60 项检查，用自己的模型 key 就能跑；Pro 版是面向企业的独立审计服务，还接入了 EU AI Act、NIST AI RMF、OWASP LLM、ISO 42001 这些合规框架的映射。

适合谁？正在把 Agent 真正推到业务里、又没法只靠自家 eval 就放心的团队——尤其是有合规、风控、治理诉求的场景。它不是"安全认证"，也不是"性能评测"，而是一套能在 CI 里重复跑的诊断工具，回答的是"能不能信任这个 Agent"这件事。方向也值得关注：当 Agent 越来越多地接管真实流程，"审计"会像代码测试一样，变成基础设施的一部分。
