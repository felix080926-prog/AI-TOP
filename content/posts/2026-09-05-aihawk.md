上周我想把某个网站一个分类里的商品全扒下来，做成一张表。按老办法，得开 Selenium、找 XPath、写翻页逻辑，一个下午就搭进去了。这次我换了做法——对着它说了句人话，剩下的它自己点、自己翻、自己填。

这工具叫 AIHawk，一个开源的 AI 浏览器智能体。你给它一个浏览器，再用大白话告诉它想干嘛，它就去打开网页、点按钮、敲键盘、读页面，把结果拿回来。

**项目地址：**https://github.com/feder-cr/AIHawk

![AIHawk 项目 banner](https://raw.githubusercontent.com/feder-cr/AIHawk/main/assets/invisible-playwright-banner.png)

## 上手只要两步

第一步，决定模型从哪来。

如果你已经在用 Claude Code、Codex、Gemini CLI，一条命令就能把浏览器挂上去，模型还是你自己的，操作习惯不变。想独立用，就跑它的 Web 界面——左边聊天框，右边一个真实的浏览器窗口，填个 OpenRouter 的 key 就能开干。

![浏览器正在打开书籍分类页](https://raw.githubusercontent.com/feder-cr/AIHawk/main/articles/extracting-a-category-to-csv/screenshots/mystery-page-1.png)

最戳我的是它"真像个人"：指针是真实移动的，按键是真实按下的，连表单都不肯用脚本直接塞值，因为网页能分辨出"机器填的"和"人填的"。做网页自动化最怕被反爬识破，它在这上面下了不少功夫。

## 最惊喜的部分

很多号称自动化的工具，其实是走 API 或者抓接口，页面一复杂就露馅。AIHawk 是真开一个浏览器，像人一样读页面、做判断。

README 里放了个完整实测：让它把某书籍分类站 32 本书全提取成 CSV，还要它自己核对数量。中间它踩了坑——第一遍读到的书名被截断、带了省略号，它没糊弄交差，而是换条路读完整标题，最后 20 + 12 = 32，跟页面自己报的数严丝合缝。还有一次让它数价格、统计区间，结果拿去跟一个纯脚本算出的 ground truth 对，数字完全一致。

![Agent 读完后供脚本核对结果](https://raw.githubusercontent.com/feder-cr/AIHawk/main/articles/web-research-audited/screenshots/catalogue-page-1.png)

这种"知道自己可能错、会回头核一遍"的劲儿，是普通爬虫脚本给不了的。这项目来头也不小，被 Business Insider、TechCrunch、The Verge 一堆媒体报过，GitHub 上三万多 Star，今天又涨了 770。

## 一个小提醒

它现在支持 Windows 和 Linux，Mac 还没适配。另外浏览器是独立下载，第一次跑会等一会儿，可以先手动 fetch 一下。

想试就一句话：clone 下来装好 uv，跑 `uvx aihawk ui --openrouter-key 你的key`，打开本地端口，对它说第一句人话。
