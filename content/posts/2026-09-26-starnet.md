AI Agent 相关的开源项目越来越多，但大多数还停在聊天框里：发一句话，它回一段，活儿干没干、干到哪一步，只能靠日志和转圈猜。想同时跑好几个 agent、还想看清谁在干什么，基本得开一堆终端窗口盯着。

StarNet 换了个思路。它把 AI Agent 装进一个像素风的太空站里——每个 agent 是站里的一个船员，有自己的工位、笔记本和权限边界。你在这个桌面应用里布置房间、连接走廊、摆放设备，这套布局本身就是 agent 的工作流。

**项目地址：**https://github.com/androoAGI/starnet

![StarNet 太空站——房间、船员与工位实时渲染](https://raw.githubusercontent.com/androoAGI/starnet/feat/harness-backend/.github/media/station-iso.png)

它最特别的一条产品纪律是：界面绝不能显示 harness 证明不了的状态。也就是说，屏幕上 agent 在跑，它就真的在跑——真实调用模型、真实执行工具、真实产生成本，不是动画演示。房间是带能力边界的团队，走廊是授权的交接通道，摆下的物体是一次真实的能力授予。布局怎么画，agent 就怎么干活。

模型可以自带：贴一个 OpenRouter key，或者用 Anthropic、OpenAI、Google 的账号登录，密钥存在系统钥匙串里，不进前端。数据也都在本地——agent 的记忆、对话记录、花销账本，全部落在自己机器上。跑一半出门了，还能从 Telegram、Discord、Slack 远程给站里派活；想让它夜间接着干，开个「Night Shift」，每一步离场动作都有日志可查。

**装起来只要几步。** 想直接跑，clone 下来用 Node 起 sidecar 就行（sidecar 只用 Node 核心模块，不用 npm install）：

```bash
git clone https://github.com/androoAGI/starnet.git
cd starnet
node sidecar/index.js
```

然后打开 http://localhost:8787 接一个 provider。想完全免费，装个 Ollama、`ollama pull llama3.1`，把 provider 选成 OLLAMA 就行。要桌面安装包，去 releases 页下 Windows 或 macOS 的安装器即可。

![StarNet logo](https://raw.githubusercontent.com/androoAGI/starnet/feat/harness-backend/.github/media/starnet-logo-glow.png)

这个项目适合手里同时跑好几个 agent、又不想盯着终端日志猜进度的人，也适合想把 agent 从「聊天玩具」推到「能持续干活的工具」的开发者。它现在 498 Star、今天涨了 93，还在早期，macOS 端的实测覆盖也不如 Windows 多，但把 agent 的运行状态做成可见、可验证的空间，这个方向值得关注。
